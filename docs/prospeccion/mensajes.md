## Referido a cliente actual

Para el entrenador de la app de entrenamiento/dieta y para Envíos ETM.

```
Hola [nombre]! ¿Cómo va todo? Te escribo porque armé un portafolio para mostrar
los proyectos que vengo desarrollando, y tu sistema está como uno de los casos
(sin mostrar datos tuyos, solo el tipo de problema que resolvimos). Te quería
pedir dos cosas si tenés un minuto:

1) ¿Me tirarías 2-3 líneas contando cómo te cambió el día a día tener el
sistema? Me serviría mucho para el portafolio.

2) ¿Se te ocurre algún otro negocio o conocido que le vendría bien algo
parecido?

Te dejo el link para que veas cómo quedó: https://desarrolloiarg-netizen.github.io/nexo-labs-portfolio/

¡Gracias!
```

## Outreach en frío (entorno cercano)

Para negocios/conocidos sin relación previa de trabajo.

```
Hola [nombre]! ¿Cómo andás? Te escribo porque armé una página con los
proyectos de software que vengo desarrollando (dashboards, apps a medida,
automatización de procesos manuales) y pensé en vos porque [razón específica:
algo que sabés de su negocio/rubro].

Si tenés algún proceso que se hace a mano (WhatsApp, Excel, papel) y te
gustaría automatizar, contame de qué se trata y vemos si te puedo ayudar.

Te dejo el link para que veas algunos casos: https://desarrolloiarg-netizen.github.io/nexo-labs-portfolio/
```
